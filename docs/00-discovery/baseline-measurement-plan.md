# Baseline Measurement Plan (TS-E0-08)

**Purpose:** measure today's effort and quality *before* TalentScout. Pilot claims are then comparisons, not guesses.

| Metric | How measured | Who | Sample |
|---|---|---|---|
| Sourcing minutes per requirement | Recruiter time log: start of search → shortlist sent to lead | 3 recruiters | 5 requirements each |
| Profiles opened per shortlist | Self-count in the log | same | same |
| Shortlist acceptance rate | Delivery Lead accepts or rejects each submitted profile | Delivery Lead | all of the above |
| Client rejection reasons | Category per rejection (skills, notice, budget, other) | Delivery Lead | 4 weeks of history |
| Time to first submission | ATS timestamps | PO | last 60 days |

**Log template (one row per requirement):** requirement code (no client name), role family, start time, end time, profiles opened, profiles shortlisted, notes.

**Limitations to state in the pilot report:** small sample, self-reported timings, no randomisation, and the novelty effect during the pilot.
